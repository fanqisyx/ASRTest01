语音助手整合软件 - 使用说明书

📋 软件概述

这是一款基于人工智能的语音助手软件，能够：

  • 实时语音识别和对话
  • 支持唤醒词唤醒
  • JSON命令自动处理和存储
  • 多语言语音合成播报

🚀 快速开始

1. 启动软件

双击 启动.bat 或运行 python main.py

2. 界面说明

⚙️ 基础配置

首次使用设置

  1. 点击 [设置] 按钮
  2. 配置以下必要参数：
设置项 说明 示例值
LMStudio地址 AI模型服务地址 http://localhost:1234/v1/chat/completions
LMStudio模型名 使用的AI模型名称 your-model-name
Vosk模型路径 语音识别模型路径 E:/AITools/model/Vosk/vosk-model-cn-0.22

🎯 使用模式

模式一：普通对话模式

  1. 点击 [开始聆听]
  2. 直接对着麦克风说话
  3. 系统自动识别语音并发送给AI
  4. AI回复后自动播报

模式二：唤醒词模式

  1. 在设置中启用 "启用唤醒词识别"
  2. 设置唤醒词（如：你好小明）
  3. 点击 [开始聆听]
  4. 说出唤醒词唤醒系统
  5. 听到"你好！"后开始对话

🔧 高级设置

唤醒词配置

  • 启用唤醒词识别：开启后需要唤醒词才能激活对话
  • 唤醒词：设置您的专属唤醒词
  • 唤醒后屏蔽唤醒词：对话期间不再检测唤醒词

自动停止设置

  • 启用定时自动停止：超时自动停止监听
  • 定时时间：设置自动停止的秒数（建议30秒）

许可证设置

  • 本机机器码：显示当前设备的唯一标识
  • 公钥路径：许可证验证公钥文件路径
  • 许可文件路径：许可证文件路径
  • 验证许可证：检查许可证是否有效

💡 功能特性

1. 智能语音识别

  • 支持中文语音识别
  • 自动过滤噪音和短词
  • 实时显示识别结果

2. AI对话处理

  • 支持思考过程显示
  • JSON命令自动识别和存储
  • 异常情况友好提示

3. 语音合成播报

  • 优先使用中文语音
  • 系统级TTS引擎
  • 播报状态智能管理

4. JSON命令处理

当AI返回JSON格式的命令时：

  • 自动添加时间戳ID
  • 格式化保存到 model_command.txt
  • 简化播报为"命令已收到"

JSON格式示例：

{
  "id": "2025-08-06 14:30:25",
  "source": "1",
  "target": "5",
  "command": "move_item"
}

⚠️ 注意事项

使用前检查

  1. 网络连接：确保能访问LMStudio服务
  2. 音频设备：检查麦克风和扬声器工作正常
  3. 模型文件：确认Vosk模型路径正确
  4. 许可证：验证许可证有效期

常见问题

  1. 无法识别语音

    • 检查麦克风权限
    • 确认Vosk模型路径
    • 调整麦克风音量

  2. AI不回复

    • 检查LMStudio服务状态
    • 确认API地址和模型名
    • 查看网络连接

  3. 语音播报异常

    • 检查系统TTS服务
    • 确认扬声器设备
    • 重启软件

  4. 许可证过期

    • 联系管理员更新许可证
    • 检查系统时间是否正确

🔍 故障排除

软件崩溃

  1. 查看 fatal_error.log 错误信息
  2. 检查Python依赖包是否完整
  3. 重新安装依赖：pip install -r requirements.txt

性能优化

  1. 关闭不必要的后台程序
  2. 使用有线网络连接
  3. 定期清理日志文件
